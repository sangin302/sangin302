특히 다음과 같은 주제에 관심이 많습니다.

## 🚀 Main Projects

### 1. SSAIREN — AI 기반 스마트 구급활동 어시스턴트 🚑
> 응급 현장의 음성을 기반으로 구급활동일지 자동 작성과 병원 자동 선별을 지원하는 서비스

- **성과**
  - SSAFY 자율 프로젝트 **최우수상**
  - 실제 구급활동일지 약 24,000건 기반 도메인 학습
  - 응답 지연시간 **67초 → 28초 단축**
  - 의료 정보 추출 정확도 **95% 이상**
- **기술**
  - `Python` `FastAPI` `Qwen` `LoRA` `GGUF` `Faster-Whisper` `Redis` `AWS`
- **핵심 구현**
  - STT 기반 현장 대화 추출
  - LLM 기반 구급활동일지 JSON 자동 생성
  - 환자 상태/거리/병상 정보를 반영한 병원 자동 선별
  - 민감 정보 보호를 고려한 경량 모델 온프레미스형 추론 구조 설계
